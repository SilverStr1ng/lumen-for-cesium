# Local GI 64MiB 资源口径 · v11

沿用 64×1048576B 附加预算。Session 合计冻结输入、Blob 数据副本、CPU 准备与常驻缓冲、原生显示几何/材质/环境、DDGI、快照、FG 附件及查询预留；这是逻辑字节合计，不能称为驱动显存。

纹理按实际 Texture/CubeMap 身份去重，原生共享 Buffer/Texture 按 Cesium allocation ID 去重。world 纹理已包括 snapshot/cache，不再叠加这两个子集。模型默认材质纹理和共用 BRDF LUT 也列入显示成本。主画面 HDR/后处理、阴影、Globe 的基础渲染资源另报独立全 Scene WebGL 峰值；此范围与旧 FG 附加预算一致，不通过移除资产或 GI 类别过关。驱动分配对齐、编译程序存储、JS allocator 和显示器延迟分别为未测量。

原生队列上限 32+128 个计时查询：预留固定 640KiB，每个在用 handle 用 4KiB 逻辑额度抵扣，避免每个 draw 重扫完整资源表。此数是公开容量估算，不是声称测出了查询对象的驱动字节。

输入限制：清单512KiB、资源最多128项、单项2MiB、总输入8MiB、资产最多32个、展开后最多200000三角形、4096探针。单个glTF最多1024节点、4096 accessors、64图片、128 buffers、128纹理、4096材质、8192 primitives，展开遍历最多200000节点访问。图片在解码前检查 PNG/JPEG 尺寸≤512。外部 buffer 长度须匹配已验证内容，GLB仅允许≤3B padding。加载前有解码、几何和原生容量预留；不够时拒绝新加载并保留匹配的旧世界。替换时统计新旧并存；已准备几何转移给 Worker，不再次加载解码。不可取消的原生 factory 在实际 settle/销毁之前继续占有预留。

Auto 从实际 drawing buffer 与上述资源/未来已准入容量规划，固定32r参考门限不变。压力可以缩小 Auto 接收附件，不改变主画面、阴影、网格、反弹或每点样本。诊断申请额度时不会触发 Auto 释放历史；额度不足明确拒绝。像素诊断只读请求的最多256个像素，几何导出/PNG编码单列预留。返回给调用者的诊断数组由调用者释放引用，不进入生产反馈。

验证同时比较账本 handle 与独立 GL texImage/bufferData/mipmap/delete 调用，并检查账本之外来自模型、环境或 Lumen 的存活分配。报告全 Scene 峰值以及保守的附加 GPU 峰值+已知 CPU 上界，避免只检查一份自报清单。任何必需资源失败都阻止 pilotReady。
