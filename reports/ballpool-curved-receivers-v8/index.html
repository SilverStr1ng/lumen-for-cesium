操作与范围

npm run setup
npm run build
npm start

默认64球可直接看静态效果；点击播放、暂停，再点击“定格并更新 GI”并等待“静态 GI 就绪”。16球为验证档；128球为压力档。Auto 保留32r并按实际 drawing buffer 规划64MiB附加资源；Interactive16 是独立质量和收敛取舍。DDGI、重建FG、仅移除局部间接光在同机位、曝光1下对照。

受控接收支持半径0.34m、不透明基础PBR球，按Ns采样并由Ng约束真实半球；稳定球体身份防止跨球借用。命中侧仍采用三角形Ng Lambert。近接触区域的独立数值误差单独保留。运动中完整多反弹GI、通用动态BVH、地形/Tiles GI和局部镜面追踪尚未实现。

持续活动成本 · 同构建控制变量

每项使用三轮整帧异步GPU query。P95表值是各轮P95的算术平均，不是合并分布的P95。CPU范围为preRender→postRender提交，物理单列。固定门限仍为 D−B≤1ms、D−A≤3ms。B=fixed raw，C=同序列去相关raw，D=重建；16r与32r属于不同质量档。

桌面 Auto / 实际覆盖

预算覆盖FG附件、历史、快照和球池新增资源，包括已知CPU几何与物理WASM保留内存。该数值不等于整个Cesium或驱动物理显存；主画面、阴影、DDGI网格和反弹保持公开配置。128球的资源通过不代表画质通过。

曲面独立误差

前景轮廓、球-地面与球-球区域分别测量，完整球面身份作覆盖分母；不剔除门控失败边缘。原close机位和低位contact机位都保留。参考采用实际几何、Ng/Ns合同、独立8192路径；截图不作为线性参考。
